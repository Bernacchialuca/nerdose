# S-001: Monorepo base, tooling y paquetes core y ui

**Status:** Ready
**Created:** 2026-11-03
**Source:** REQ-001

## Historia de Usuario

**Como** desarrollador de Nerdose,
**quiero** un monorepo pnpm + Turborepo con lint, typecheck y test funcionando, y los paquetes compartidos `core` y `ui` iniciales,
**para** que todos los servicios se construyan sobre una estructura común con los límites de importación ya forzados.

## Criterios de Aceptación

### CA-1: Monorepo con scripts globales

**DADO** un repositorio con Node 24 y pnpm instalados
**CUANDO** se ejecutan `pnpm lint`, `pnpm typecheck` y `pnpm test`
**ENTONCES** los tres pasan en todos los paquetes (REQ AC 11)

### CA-2: Registro de juegos vacío

**DADO** el paquete `core` con el contrato `GameDefinition` y `createGameRegistry([])`
**CUANDO** se consulta `get` con un `game_id` cualquiera
**ENTONCES** se lanza `AppError('not_found')` del `ERROR_CATALOG`, sin excepción no manejada (REQ AC 12)

### CA-3: Ids duplicados

**DADO** `createGameRegistry` recibe dos definiciones con el mismo id
**CUANDO** se construye el registro
**ENTONCES** falla al construirse

### CA-4: Tokens visuales

**DADO** el paquete `ui` con `tokens.css`
**CUANDO** se inspecciona el bloque `@theme`
**ENTONCES** declara `--color-bg: #0A0C0F`, `--color-accent: #3DDC84` y `--font-mono` (REQ AC 7, parte de tokens)

### CA-5: Límites de importación

**DADO** la configuración de ESLint con `no-restricted-imports`
**CUANDO** `apps/web` o `apps/admin` importan `@nerdose/db` o `@nerdose/core/notify`, o una app importa de otra
**ENTONCES** el lint falla (ADR-003)

### CA-6: Sin secretos versionados

**DADO** el repositorio recién clonado
**CUANDO** se revisan los archivos versionados
**ENTONCES** `.gitignore` excluye `.env`, `.env.local` y `.env.test` y no hay secretos reales (REQ AC 16)

### Flujo de Interacción y Consideraciones Técnicas

- **Paquetes internos sin build (JIT):** `core`, `ui` (y `db`) exportan su TypeScript fuente por `exports` (`"."` → `./src/index.ts`); `typecheck` es `tsc --noEmit` por paquete.
- **Lint:** ESLint flat config + typescript-eslint; `eslint-plugin-react-hooks` y `jsx-a11y` en las SPAs; `no-restricted-imports` fuerza los límites de ADR-003.
- **`createGameRegistry(definitions)`** devuelve `{ ids(), get(id) }`; `get` lanza `AppError('not_found')` (status 404) si no está registrado; ids repetidos fallan al construir.
- **Alcance de `core`:** entrada `.` isomorfa (no importa `node:*`). `./notify`, `GameGenerator`, `VerificationLog`, `HistoryItem` y `VerifyContext` quedan para feature groups posteriores.
- **Pruebas:** `core` (registro vacío, id duplicado, `AppError` toma el status del catálogo); `ui` (tokens y `cn()` resuelve conflictos de clases).
