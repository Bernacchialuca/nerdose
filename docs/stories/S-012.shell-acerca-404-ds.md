# S-012: Shell, "Acerca de" y 404 alineados al DS

**Status:** Ready
**Created:** 2026-11-06
**Source:** REQ-003

## Historia de Usuario

**Como** jugador de Nerdose,
**quiero** que el header, la navegación, el selector de idioma, el footer y las páginas "Acerca de" y 404 tengan la identidad del prototipo,
**para** reconocer la plataforma igual en todas las rutas, también en un celular de 320 px.

## Criterios de Aceptación

### CA-1: Header del prototipo

**DADO** cualquier ruta
**CUANDO** se muestra el header
**ENTONCES** tiene padding 18/32, borde inferior, logo `> nerdose_` con `>` y `_` en verde, nav siempre dentro del header con `flex-wrap` y el ítem activo según el DS (REQ RF 3, 4)

### CA-2: Píldora de racha y número

**DADO** un jugador con racha global de N días
**CUANDO** abre cualquier ruta
**ENTONCES** ve la píldora de racha (link a `/stats`, `aria-label` "Racha global: N días") y el `#número` del desafío; si `GET /api/today` falla ambos se ocultan (REQ CA 5)

### CA-3: Selector de idioma segmentado

**DADO** el selector ES/EN
**CUANDO** el jugador cambia de idioma
**ENTONCES** es un grupo (`role="group"`, `aria-pressed`, `lang` por segmento) con área táctil de 44 px y señal adicional del activo, y el comportamiento de REQ-002 no cambia (REQ RF 5)

### CA-4: Footer

**DADO** cualquier ruta
**CUANDO** se muestra el footer
**ENTONCES** tiene el lema y `exit 0` del prototipo y conserva el aviso de privacidad y el enlace a "Acerca de" (REQ RF 6)

### CA-5: Layout y fondo

**DADO** cualquier ruta
**CUANDO** se renderiza
**ENTONCES** el contenedor es `max-w-page` (1240 px) con gutter de 32 px, sin media queries globales (se eliminan `lib/breakpoints.ts` y el uso de `useMediaQuery` en el shell), y la home lleva el fondo `texture-dots` (REQ RF 7)

### CA-6: Aviso de cookies bloqueadas

**DADO** cookies bloqueadas
**CUANDO** aparece el aviso O-03
**ENTONCES** es el `Banner warning` del DS, alineado al contenedor de página, con `role="status"` (REQ CA 9)

### CA-7: "Acerca de" y 404

**DADO** las rutas `/about` y una ruta inexistente
**CUANDO** se muestran
**ENTONCES** usan `Panel` y la tipografía del DS (radio 14, sin peso 600), con links y botones del DS, y el error de ruta usa el mismo estilo (REQ RF 11, 13)

### CA-8: 320 px y accesibilidad

**DADO** un viewport de 320 px
**CUANDO** se recorren "Acerca de" y la 404 (y el shell de home)
**ENTONCES** no hay scroll horizontal, nav y selector siguen accesibles y axe-core no reporta violaciones (REQ CA 2)

### CA-9: Comportamiento de REQ-002

**DADO** los tests de comportamiento de REQ-002 (sesión, idioma, cookies bloqueadas, 404)
**CUANDO** se corren
**ENTONCES** pasan; solo se ajustan los que fijaban clases o la nav duplicada en mobile (REQ CA 12)

## Diseño Técnico

### Servicios Afectados

| Servicio | Impacto | Cambios Necesarios | Estado |
|----------|---------|-------------------|--------|
| web | Alto | `app/shell.tsx`, `main-nav.tsx`, `site-footer.tsx`, selector de idioma, banner O-03, layout, `index.css`, `modules/about`, `app/not-found.tsx`, `app/route-error.tsx`, claves i18n ES/EN, tests | Done |

### Cambios de API

Ninguno. Reutiliza `GET /api/today` (la píldora y el `#número` leen la misma query cacheada), `POST /api/session` y `PATCH /api/me/preferences`.

### Cambios de Base de Datos

Ninguno.

### Decisiones de diseño aplicables (REQ-003)

- Decisión 4: `StreakPill` y el ítem de nav reciben el `<Link>` armado desde `web`.
- Decisión 5: sin media queries globales; grilla con flex-wrap / auto-fit; gutter 32 px (el DS no define reducción); piezas que no entren en 256 px se adaptan una a una.
- Decisión 7: hover de nav/link/píldora/segmento, área táctil de 44 px, señal del segmento activo, estado sin racha / sin sesión de la píldora, ubicación de privacidad y "Acerca de" en el footer.
- Decisión 8: `font-sans` como base de página; cada pieza de interfaz declara `font-mono`.

### Flujo de Interacción

#### Escenario: cambio de idioma (comportamiento sin cambios)

1. **[web - shell]** `SegmentedControl` llama al mismo handler: `PATCH /api/me/preferences { "locale": "en" }`, o solo cambio en cliente con cookies bloqueadas.
2. **[web]** `i18n.changeLanguage`, `<html lang>` e invalidación de queries de contenido.

### Flujos Afectados

- **preferencias-y-share** (ref: docs/flows/preferencias-y-share.md): paso 1, solo cambia cómo se ve el selector.
- **primera-visita-y-sesion** (ref: docs/flows/primera-visita-y-sesion.md): sin cambios de contrato.

### Consideraciones Técnicas

**Riesgos:** scroll horizontal a 320 px con el header (varios grupos); `min-width: 0` en hijos flex y flex-wrap. Tests que consultan nav duplicada en mobile.

**Revisión UX (REQ-003):** pantallas `acerca-de`, `no-encontrado`, `estadisticas` (solo shell), overlay O-03 y footer de las pantallas de juego, en `docs/ux/surfaces/web/`.
