# Tokens

## tokens.css
- **Location:** packages/ui/src/tokens.css (exported as `@nerdose/ui/tokens.css`)
- **Description:** Single `@theme` block (DS `web` 1.7.0, additive over the original 21 tokens): `--font-sans` (Inter) and `--font-mono` with ligatures off; neutrals (`surface-*`, `control*`, `toolbar`, `titlebar`, `nav-active`, `track`, `window-dot`, `header`, `text-body|lede|disabled|…`, `border-hover|emphasis`); per-game scale `--color-game-{id}-on|tint|border|muted|light|featured` plus extras (incl. `--color-game-grep-grid-selected-bg|found-bg`); status (`--color-status-*`, incl. `present`, `absent-bg|text`, `success-row-bg` and `misplaced-bg|border`), `--color-text-separator` and streak (`--color-streak*`, always amber); 40 typographic roles (incl. `numeric-lg`, `display-score`, `numeric-year`, `game-item`, game screens: `title-game`, `brand-logo-compact`, `brand-crumb`, `game-tile-*`, `game-key*`, `body-sm*`, `code-share`) `--text-*` with line-height, tracking and weight; radii (`--radius-*`), `--container-page|lede|keyboard|devdle-aside`, shadows (`--shadow-window`, `--shadow-next-{id}`, `--shadow-bar-bug-hunt`); `--animate-blink` (4 cycles) with its `@keyframes`. Outside `@theme` only `@source "./components";` and `@utility texture-dots`. Dark only.
- **Usage:** `@import '@nerdose/ui/tokens.css';` in each app's `src/index.css`, then use `bg-surface-inset`, `text-streak`, `text-display-hero`, `text-numeric-lg`, `text-display-score`, `bg-status-misplaced-bg`, `rounded-panel`, `max-w-page`, `texture-dots`, `motion-safe:animate-blink`.
